# 7.6 Activity: where the logic branches

## `save()`: save or skip

```mermaid
flowchart TD
  S(["save(opts)"]) --> T["clear timer"]
  T --> IF{"inflight?"}
  IF -->|yes| W["await inflight"] --> P
  IF -->|no| P{"this.page?"}
  P -->|null| X(["return"])
  P -->|set| SN["snap = snapshot()"]
  SN --> EQ{"snap === savedSnapshot?"}
  EQ -->|yes| OK1["dirty = false<br/>status 'saved'"] --> X
  EQ -->|no| REQ["status 'saving'<br/>PATCH /api/pages/:id"]
  REQ --> R{"response"}
  R -->|"200"| SAME{"this.page === page?"}
  SAME -->|yes| SV["savedSnapshot = snap"] --> NT{"timer set?<br/>(edited meanwhile)"}
  NT -->|no| OK2["dirty = false<br/>status 'saved'"]
  NT -->|yes| KEEP["stay dirty"]
  SAME -->|no| EV
  OK2 --> EV["emit 'saved'"]
  KEEP --> EV
  R -->|"throws"| ER["status 'error'"] --> SP{"still same page?"}
  SP -->|yes| RT["dirty = true<br/>retry in 4000 ms"]
  SP -->|no| X
```

## Mouse down on the canvas

```mermaid
flowchart TD
  M(["mousedown on #pageInner"]) --> B{"button === 0?"}
  B -->|no| N(["ignore"])
  B -->|yes| MD{"mode === 'type'?"}
  MD -->|no| INK(["ink layer handles it:<br/>draw or erase"])
  MD -->|yes| TG{"target === #pageInner?<br/>(empty canvas, not a container)"}
  TG -->|no| N2(["browser default:<br/>caret / selection in container"])
  TG -->|yes| PG{"page loaded?"}
  PG -->|no| N
  PG -->|yes| NEW["addBlock at (x − 8, y − 10) ÷ zoom<br/>min y 12, focusBlock()"]
  NEW --> BLUR{"later: focus leaves block<br/>and isEmptyBlock()?"}
  BLUR -->|yes| RM["remove block, scheduleSave()<br/>(save skips: snapshot unchanged)"]
  BLUR -->|no| KEEP(["block stays"])
```

**Why the focus check ignores the ribbon:** clicking the font-size box moves focus out of the
container. The `focusout` handler skips removal when focus went to `.ribbon`, `.menu` or a modal,
so a fresh empty container survives choosing its formatting first.

## Where a new planner task lands

```mermaid
flowchart TD
  IN(["Enter in an add box<br/>of group g"]) --> P["parseQuickAdd(raw, {defaultMonth: g.month})"]
  P --> TXT{"text left after<br/>removing #tag / @date?"}
  TXT -->|no| T0(["toast: type the task itself"])
  TXT -->|yes| TAG["tag = parsed.tag ?? g.tag ?? null"]
  TAG --> D{"parsed.date?"}
  D -->|yes| D1["date = parsed.date<br/>month = date's month"]
  D -->|no| D2["date = g.date ?? null<br/>month = date's month, else g.month ?? null"]
  D1 --> ADD["push task, ensure its month exists,<br/>render, scheduleSave()"]
  D2 --> ADD
  ADD --> MOV{"Month view and<br/>month ≠ g.month?"}
  MOV -->|yes| TO(["toast: Added to November (20 Nov)"])
  MOV -->|no| DONE(["focus stays in the same add box"])
```

Group kinds that set defaults: a month group (`g.month`), a date group (`g.date`, `g.month`), a
tag group (`g.tag`), "No date" / "No tag" / "Unscheduled" (nothing), and the top add box in
Date and Tag views (nothing). The Overdue group has no add box.

## Where a dropped planner task lands

```mermaid
flowchart TD
  IN(["drop (or Alt+arrow) of task t<br/>onto group g"]) --> OV{"g is Overdue?"}
  OV -->|yes| NO(["refused: no drop marker, nothing changes"])
  OV -->|no| K{"g.kind"}
  K -->|month| M["t.month = g.month<br/>t.date outside g.month → null"]
  K -->|unscheduled| U["t.month = null, t.date = null"]
  K -->|date| D["t.date = g.date, t.month = g.month"]
  K -->|nodate| ND["t.date = null"]
  K -->|tag| T["t.tag = g.tag (No tag → null)"]
  M --> POS
  U --> POS
  D --> POS
  ND --> POS
  T --> POS
  POS["splice t out of data.tasks;<br/>insert before the task under the pointer,<br/>else after g's last task"] --> SAVE(["render, refocus t, scheduleSave()"])
```

`applyGroup()` + `moveTask()` in `todo.js`. Alt+↑/↓ is the same move with "before" = the
neighbouring task; Alt+←/→ is a drop at the end of the previous/next non-Overdue group.

## Paste into a container

```mermaid
flowchart TD
  P(["paste event in .nb-content"]) --> F{"clipboardData.files?"}
  F -->|"1+ files"| UP["preventDefault<br/>insertFiles(): upload each,<br/>img for image/*, attachment otherwise"]
  F -->|none| H{"text/html present?"}
  H -->|no| DEF(["browser default:<br/>plain text"])
  H -->|yes| OWN{"types include<br/>application/x-onenote-clone?"}
  OWN -->|yes| S1["sanitizeHtml(html, own = true)<br/>keep style, class, data-*"]
  OWN -->|no| S2["sanitizeHtml(html, own = false)<br/>keep only weight/style/decoration/align"]
  S1 --> INS["insertHTML"]
  S2 --> INS
```

Both sanitiser paths drop `<script>`, `<style>`, `<iframe>`, forms, all `on*` attributes,
non-http(s) links, and any `<img>` left without a `src` (P4).
