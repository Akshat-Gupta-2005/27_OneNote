# 7.4 Sequences

## Typing → durable

```mermaid
sequenceDiagram
  actor U as Owner
  participant C as .nb-content
  participant E as PageEditor
  participant A as app.js
  participant S as server/index.js
  participant D as SQLite (WAL)
  U->>C: keystroke
  C->>E: input event
  E->>E: fixFontSizes(), scheduleSave()
  E-->>A: status 'dirty' → "Saving…"
  Note over E: 600 ms with no further input
  E->>E: save(): snapshot === savedSnapshot?
  alt unchanged
    E-->>A: status 'saved' (no request)
  else changed
    E->>S: PATCH /api/pages/:id {title, content, text}
    S->>D: UPDATE pages … updated_at = now
    D-->>S: ok
    S-->>E: 200 page list form
    E-->>A: saved(res), status 'saved'
    A->>A: update page list (re-sort if by modified/title)
  end
```

**Why the snapshot check:** without it, clicking and leaving an empty container saves and bumps
`updated_at`. Measured: 0 requests with the check, 1 with it removed (2026-10-15).

## Server down during an edit

```mermaid
sequenceDiagram
  participant E as PageEditor
  participant A as app.js
  participant S as server
  E->>S: PATCH (server down)
  S--xE: network error
  E-->>A: status 'error'
  A->>A: first error since 'saved'? → one toast (P7)
  loop every 4 s
    E->>S: PATCH
    S--xE: network error
    E-->>A: 'saving' → 'error' (no new toast)
  end
  Note over S: server restarted
  E->>S: PATCH
  S-->>E: 200
  E-->>A: 'saved' → "All changes saved", toast flag reset
```

## Opening a page from a link, Back, or a search result

```mermaid
sequenceDiagram
  participant B as Browser history
  participant A as app.js
  participant E as PageEditor
  participant S as server
  B->>A: popstate (#/page/:id) or navigateToPage(id)
  A->>A: editor.page.id === id? → stop
  A->>E: flush() (finish pending save of current page)
  A->>S: GET /api/pages/:id
  alt 404
    S-->>A: {error:'Page not found'} → toast, stay on current page
  else deleted_at not null
    S-->>A: page → toast "in Deleted pages", stay
  else live page
    S-->>A: page (with notebook_id)
    opt different notebook, or page not in loaded tree
      A->>S: GET /api/notebooks/:nb/tree
      S-->>A: {notebook, sections, pages}
    end
    A->>A: renderSections(), renderPages()
    A->>E: load(page)
  end
```

**Why `openSeq`:** each open increments a counter and drops its result if a newer open started
meanwhile, so fast clicking through pages can't load an older page last.

## New page from a template, then adding a planner task

```mermaid
sequenceDiagram
  actor U as Owner
  participant A as app.js
  participant T as templates.js
  participant S as server
  participant E as PageEditor
  participant V as TodoView
  U->>A: Add page ▾ → To-do planner
  A->>E: flush()
  A->>T: build(new Date())
  T-->>A: {title, content: JSON string, text}
  A->>S: POST /api/pages {section_id, title, content, text}
  S-->>A: 201 page
  A->>S: GET /api/notebooks/:nb/tree
  A->>S: GET /api/pages/:id
  A->>E: load(page)
  E->>E: content.type === 'todo' → kind = 'todo'
  E->>V: mount(inner, head, data, pageId)
  U->>V: types "Sign offer #Sabre @20 Oct" + Enter
  V->>V: parseQuickAdd() → {text, tag, date}
  V->>V: change(): month = date's month, render()
  V->>E: onChange() → scheduleSave()
  Note over E,S: same 600 ms autosave as a canvas page
```

**Why one POST with the content:** the page never exists empty, and its text is searchable at
once (tested: `milestones` finds a fresh Project plan with no edits).

## Loading the app: the theme before first paint

```mermaid
sequenceDiagram
  participant B as Browser
  participant H as index.html inline script
  participant A as app.js
  participant T as theme.js
  participant S as server
  B->>H: parse <head>
  H->>H: read localStorage oc.appearance
  H->>B: set data-theme, data-density…, --tokens, --font-ui
  Note over B: first paint already in the right colors
  B->>A: load module
  A->>S: GET /api/settings
  S-->>A: {appearance, displayName}
  A->>T: initAppearance({settings, save})
  T->>T: normalizeAppearance() (drops invalid themes, unknown ids → Classic)
  T->>B: apply: data-theme, tokens, data-* look, --font-ui
  T->>B: write oc.appearance (for next load)
  T-->>A: 'appearancechange' → renderThemeTab()
```

**Why two applies:** the cache can be stale (another browser changed the theme), so the server's
copy always wins a moment later. The cache only decides the first frame. Tested by blocking
`app.js` entirely: the cached accent and density still apply.

## Insert → Templates (since 2026-10-17)

```mermaid
sequenceDiagram
  actor U as Owner
  participant A as app.js
  participant T as templates.js
  participant E as PageEditor
  U->>A: Insert → Templates → Project plan
  A->>A: editor.structured? → toast, stop
  A->>T: build(now) → {title, blocks}
  alt page has no title
    A->>E: setTitle(title)
  else one container
    A->>A: prepend <h1>title</h1>
  else several containers
    A->>A: add a heading container above them
  end
  A->>E: insertBlocks(specs)
  E->>E: top = lowest container bottom + 40 (or 100 on an empty page)
  E->>E: addBlock() each, keeping relative x/y
  E->>E: scheduleSave()
  A-->>U: toast "Inserted Project plan" [Undo]
```

**Why below, not at the caret:** a template is several positioned containers. Dropping them at
the caret would overlap whatever is there; below the lowest container never overlaps.

## Inserting a picture

```mermaid
sequenceDiagram
  actor U as Owner
  participant A as app.js
  participant E as PageEditor
  participant S as server
  participant F as data/uploads
  U->>A: Insert → Picture
  A->>E: ensureCaret() (restore selection or create a container)
  A->>U: file picker
  U->>E: chooses file(s)
  E->>S: POST /api/uploads (octet-stream, X-Filename)
  S->>F: write <uuid>.<ext>
  S-->>E: {url, name, size}
  E->>E: restoreSelection(), insertHTML('<img data-new …>')
  E->>E: strip style + data-new from new <img> (P3)
  E->>E: scheduleSave()
```

**Why octet-stream:** a JSON file sent as `application/json` would be eaten by the global JSON
parser (`400 Empty upload`, observed 2026-10-15).
